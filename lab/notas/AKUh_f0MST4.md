# Así Creo Canales de 24M de Visitas de Historia en 10 Minutos · Ale Ferr

**Gancho:** "hay un nicho faceless que lo está petando" + 3 canales en pantalla (historia con animaciones) + "todo animado con Claude, sin pagar otras herramientas" + regalo ("te entrego gratis el **motor gráfico**").
**Qué enseña (5 pasos):** app de escritorio de Claude → carpeta "historia animada" → Claude Code (Opus, esfuerzo medio, permisos automáticos) → pegar un prompt que **instala un motor gráfico** → Claude propone ideas o eliges una (vikingos) → escribe el guion "optimizado para el nicho" → voz en ElevenLabs → arrastrar el audio a la carpeta "pon aquí tu voz" → Claude **anima el video** (~8–10 min para 5 min de video en un computador moderno) → carpeta "videos listos" con **MP4 + txt (título, descripción, capítulos)**.
**Monetiza:** documento gratis (lead) + **club pago** con un "agente montador" para cualquier estilo (animales, stickman, 3D, películas, Shorts).

**Visual:** cara pequeña + grabación de pantalla; **los ejemplos de historia animada**: dibujo 2D plano tipo caricatura (soldados, castillos, mapas de Europa con flechas, globos de diálogo, personajes medievales), colores cálidos, miniaturas con mapas/banderas y personaje caricaturesco. 8,4 cortes/min.

**Para nosotros (⭐ muy relevante):**
- Es **casi nuestro kit**, ya en el mercado y gratis como lead: "motor gráfico para Claude Code + carpeta + voz + video listo". Valida la idea, pero **compite**: nuestro diferencial tendría que ser calidad (estilo película con personajes que actúan, cámara, luces), **medición** (reporte semanal) y el playbook.
- **Nicho: documentales de historia animados (largos, 8–20 min)** → monetizan por horas de visualización. Nuestro motor ya tiene personajes, decorados y mapas: falta un "modo documental largo" (escenas encadenadas, mapas con rutas, líneas de tiempo).
